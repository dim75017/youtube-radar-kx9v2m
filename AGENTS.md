# Règles du projet

## Navigation connectée Instagram/TikTok

- Tout scroll connecté Instagram ou TikTok utilise exclusivement un onglet ou une fenêtre de navigation privée explicitement confié(e) par Dim pour la mission courante.
- Ne jamais utiliser, lire, modifier ni entraîner le profil Chrome classique connecté à Lofi Girl.
- Une connexion existante ou une autorisation antérieure ne vaut pas délégation.
- Sans onglet privé explicitement confié dans le message courant, ne pas lancer le scroll connecté.
- Ne jamais enregistrer de mot de passe, cookie, jeton, secret, en-tête d’autorisation ou donnée de session dans le dépôt, les snapshots ou la mémoire partagée.
